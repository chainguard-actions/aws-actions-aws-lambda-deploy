# aws-actions/aws-lambda-deploy

Updates the code and configuration of AWS Lambda functions. If the function does not exist, a new one will be created.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/aws-actions/aws-lambda-deploy](https://github.com/aws-actions/aws-lambda-deploy).
